# Nexora

A responsive landing page for **Nexora**, a fictional productivity workspace designed to help teams organise projects and stay focused.

**Live website:** https://nexora-landing-page-two.vercel.app

## Features

- Responsive layout and mobile navigation
- Product dashboard mockup with interactive chart tooltips
- Week/month chart switching
- Smooth scrolling and subtle reveal animations
- Accessible controls and reduced-motion support

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: DM Serif Display and DM Sans

Built as a Frontend Development internship task. Nexora is a fictional product concept.
